# P0 — Diagnostic & Evidence Matrix (source-verified at `20aa4a1`)

**Rule:** Built firmware ≠ installed firmware. Transmitted reply ≠ host-received
reply. Software disable ≠ verified electrical shutdown. Host PASS ≠ safety
qualification. Each row names what the diagnostic actually proves and the physical
measurement still owed. Block E NOT EXECUTED; Block F NOT AUTHORIZED.
